# Квест «Карина 35» 🎁

Веб-игра для iPhone: поиск подарков по квартире с QR-кодами, викториной, мини-игрой «Кто это?» и 35 причинами любви.

- `index.html` — игра
- `config.js` — **все тексты** (загадки, викторина, причины, письмо, расписание)
- `qr.html` — страница печати QR-карточек, `QR-карточки.pdf` — готовый PDF
- `photos/` — фото; `photos/places/kofe.jpg`, `shkaf.jpg`, `krovat.jpg` — фото-подсказки мест (необязательно)

## Запуск
1. GitHub → Settings → Pages → Deploy from a branch → эта ветка, папка `/ (root)`.
2. Игра: `https://lahmatov.github.io/-/`, QR: `https://lahmatov.github.io/-/qr.html`.
3. Сброс прогресса: `https://lahmatov.github.io/-/?reset=1`.

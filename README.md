# Квест «Карина 35» 🎁

Веб-игра для iPhone: 10 загадок, ответы открывают слова португальской фразы, фраза говорит, где спрятан подарок.

- `index.html` — игра
- `config.js` — **все тексты**: загадки, ответы, португальские фразы, викторина «Кто это?», причины, письмо, стикеры
- `photos/` — фото и стикеры, `tools/make_stickers.py` — нарезка стикеров по контуру

Сброс прогресса: добавь `?reset=1` к адресу игры.

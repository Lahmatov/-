# Квест «Карина 35» 🎁

Веб-игра для iPhone: поиск подарков по квартире с QR-кодами, викториной и 35 причинами любви.

- `index.html` — сама игра
- `config.js` — **все тексты** (загадки, викторина, 35 причин, письмо). Строки с `// ЗАМЕНИ` нужно поправить.
- `qr.html` — страница для печати QR-карточек
- `photo.jpg` — (необязательно) фото для финального экрана

## Как запустить
1. GitHub → Settings → Pages → Source: *Deploy from a branch*, ветка с игрой, папка `/ (root)`.
2. Через минуту игра будет по адресу `https://lahmatov.github.io/-/`.
3. Открой `https://lahmatov.github.io/-/qr.html` и распечатай карточки.
4. Пройди игру сам для проверки, потом сбрось прогресс: открой `https://lahmatov.github.io/-/?reset=1` на телефоне Карины (или просто дай ей начать на её телефоне).

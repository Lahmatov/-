СТИКЕРПАК «КАРИНА 35» 🎁

TELEGRAM (папка telegram, PNG 512px):
1. Открой в Telegram бота @Stickers и отправь /newpack
2. Напиши название: Карина 35
3. По одному отправляй файлы из папки как ФАЙЛ (не как фото), после каждого отправляй эмодзи из списка ниже
4. Когда всё загрузишь: /publish, потом /skip для иконки, потом короткое имя, например karina35_family
5. Ссылка будет t.me/addstickers/karina35_family

WHATSAPP (папка whatsapp, WEBP 512x512 + tray.png):
Встроенного импорта в WhatsApp нет. Поставь приложение Sticker Maker (App Store),
создай пакет, добавь картинки из папки whatsapp и нажми «Add to WhatsApp».
